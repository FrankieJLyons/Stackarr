STEP 1

Choose your home network

Select the Wi-Fi or Ethernet connection your other computers use. Preparation saves a separate setup folder.

Enter network details

An IP address works without DNS setup. An optional computer name must resolve to this address on each device. Use a private IPv4 address and a specific home subnet.

Ask your router to keep this computer’s address reserved. A changing address can interrupt access. This setup does not change router or Windows settings.

PREPARED

Your address is saved

This address opens Stackarr. App links need their own configured secure routes. Devices can reuse this trust certificate for apps served by the same gateway.

What happens when I enable access?

Enabling this address briefly restarts Stackarr and saves an encrypted rollback checkpoint. Media apps keep running. Use a spare test host while device and reboot checks are pending.

STEP 2

Connect another computer

Prepare your local HTTPS address first, then return here to connect another device.

  1. Keep a way back in. Save the local address shown below on your server.
  2. Download the public certificate. Transfer only this file to the computer you want to connect. Keep the setup folder and private keys on the server.
  3. Compare its identity. Match the SHA-256 certificate fingerprint with the one displayed here on your server.
  4. Trust it once on that device. Choose your device below for instructions. Trust is normally shared by the device’s browsers; some browsers need a separate import.
  5. Open the secure address and sign in. The browser must show a valid connection. Use your Stackarr owner password. Do not continue past a certificate warning.

One certificate, once per device. You do not need to download a different certificate for each app or browser using the same trust store. This stays local; no domain, cloud account or router port forwarding is needed.

Firewall and connection help

No firewall rule is added here. On the spare host, review an inbound TCP rule limited to the chosen server address, port, home subnet and Private profile. Keep its exact name and settings for reversal. Do not open router ports or disable the firewall.

If you use a guest Wi-Fi network, device isolation may block the connection. Move the test client to the reviewed home network instead of broadening access.

RECOVERY

Get back to your dashboard

Start here on the server if another computer cannot connect. Keep the saved setup folder; it holds your certificate identity and recovery references.

Open on this computer

  • Docker is unavailable: open Docker Desktop, wait for its engine, then check again.
  • Address or port changed: restore the reserved address or free the chosen port. Existing services are never stopped to make room.
  • Certificate warning: compare the saved fingerprint and date. Never bypass browser validation or replace the private certificate folder to hide the warning.
  • After Windows restarts: reopen Start Stackarr, then Home network & recovery and Start secure access. Startup while signed out is still pending.

Turning off home access restores its earlier settings checkpoint. Local access remains your recovery route. Certificates and app data are retained.
